## 🛠️ Tech Stack & Technologies Used

This project is built using modern web development technologies:

* **Framework:** [Next.js](App Router)
* **Styling:** [Tailwind CSS]& [daisyUI]
* **Authentication:** [Better Auth]
* **Database:** MongoDB & MongoDB Atlas
* **Deployment:** Vercel

---

## ✨ Features

* **Secure Authentication:** User sign-up, sign-in, and session management powered by Better Auth.
* **Dynamic Routing:** Seamless page navigation using Next.js App Router.
* **Responsive Design:** Fully mobile-friendly and clean user interface styled with Tailwind CSS & daisyUI.
* **Interactive UI:** Smooth loaders, error boundaries, and instant feedback for users.
* **Using Toastify:** Toast Notification showing
